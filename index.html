About Me

개발자 소개

저는 기술로 교육적 가치를 창출하는 데 관심이 많은 풀스택 개발자입니다. 단순히 기능을 구현하는 것을 넘어, 사용자가 실제로 성장할 수 있는 플랫폼을 만드는 것에 열정을 가지고 있습니다. React, Node.js, 그리고 AI API를 활용하여 현실적인 문제를 해결하는 웹 애플리케이션 개발에 집중하고 있습니다.

이 협상 시뮬레이터 프로젝트를 통해 프론트엔드부터 백엔드, 게임 엔진 통합, AI API 연동까지 풀스택 개발의 전 과정을 경험했습니다. 특히 Phaser 3 게임 엔진을 React와 통합하여 게임형 UI를 구현하고, Claude AI를 활용한 실시간 대화 시스템과 피드백 시스템을 설계하며, 사용자 경험을 극대화하는 방법을 깊이 고민했습니다.

현재는 사용자 중심의 웹 애플리케이션 개발에 집중하고 있으며, AI 기술을 실제 서비스에 효과적으로 통합하는 방법을 연구하고 있습니다. 특히 교육 기술(EdTech) 분야에서 AI를 활용한 개인화 학습 경험을 제공하는 것에 관심이 많습니다.

About This Project

사용자 경험과 AI 기술의 융합

협상 시뮬레이터는 Claude AI를 활용한 혁신적인 협상 연습 플랫폼입니다. 실제 협상 상황을 시뮬레이션하여 사용자들이 안전한 환경에서 협상 기술을 연습하고 향상시킬 수 있도록 설계되었습니다.

이 프로젝트를 통해 프론트엔드부터 백엔드, AI API 통합, 그리고 사용자 인증/데이터베이스 관리까지 풀스택 개발 역량을 종합적으로 보여주고자 했습니다. 특히 React의 최신 기능, RESTful API 설계, 그리고 Claude AI의 강력한 대화 능력을 효과적으로 결합하는 데 중점을 두었습니다.

💡 핵심 가치: 단순한 기술 구현을 넘어, 사용자가 실제로 협상 스킬을 향상시킬 수 있는 교육적 가치를 제공하는 플랫폼을 만들고자 했습니다.

📌 문제 정의 & 목표

협상 기술은 비즈니스와 일상생활에서 필수적인 역량이지만, 실전 경험을 쌓기 어려운 분야입니다. 기존의 협상 교육은 이론 중심이거나, 실습 기회가 제한적이어서 실제 상황에 적용하기 어렵다는 문제가 있습니다.

이 프로젝트는 Claude AI의 자연스러운 대화 능력을 활용하여, 사용자가 언제든지 다양한 협상 시나리오를 연습하고 즉각적인 피드백을 받을 수 있는 플랫폼을 제공하는 것을 목표로 했습니다. 특히 5가지 현실적인 시나리오(연봉협상, 계약협상, 프로젝트 관리 등)를 통해 실전 감각을 키울 수 있도록 설계했습니다.

🏗️ 아키텍처 & 설계

프로젝트는 클라이언트-서버 분리 아키텍처로 설계되었습니다. React 기반 SPA(Single Page Application)로 프론트엔드를 구성하고, Node.js/Express로 RESTful API 서버를 구축했습니다.

  • Frontend (React + Vite): 빠른 개발 환경과 최적화된 번들링을 위해 Vite를 선택. React Router로 SPA 라우팅 구현
  • Backend (Node.js + Express): RESTful API 서버로 클라이언트 요청 처리 및 Claude AI API 통신 담당
  • Claude AI Integration: Anthropic SDK를 활용하여 자연스러운 협상 대화 및 실시간 피드백 생성
  • Firebase: Authentication (이메일/Google OAuth)과 Firestore (대화 기록, 사용자 데이터) 통합
  • 상태 관리: React Context API로 전역 인증 상태 관리, Axios로 API 통신 추상화
🎮 Phaser 3 기반 게임형 인터랙티브 UI

Phaser 3 게임 엔진을 React와 통합하여 몰입감 있는 협상 환경을 구현했습니다. 실시간 캐릭터 애니메이션으로 NPC의 감정 변화를 시각적으로 표현하고, 시나리오별 맞춤 배경으로 분위기를 연출합니다.

메시지 전송, 성공, 실패 등의 상황에 맞는 사운드 효과를 추가하여 인터랙티브한 경험을 제공합니다. GameScene.js에서 Phaser 씬을 관리하고, PhaserGame.jsx 컴포넌트로 React와 연결했습니다.

Phaser 3 2D Game Engine Character Animation Sound Manager Dynamic Backgrounds
🤖 AI 응답 선택지 & 실시간 메시지 피드백

대화가 막막할 때 AI가 3가지 전략적 응답을 추천해주는 시스템을 구현했습니다. (최대 3회 사용 가능) 사용자의 현재 협상 맥락을 분석하여, 공감형/논리형/전략형 등 다양한 접근 방식을 제안합니다.

각 메시지마다 실시간 피드백(탁월/좋음/보통/미흡)을 제공하고, NPC의 감정 상태와 호감도를 실시간으로 추적합니다. 별점 평가 시스템(1-5점)으로 협상 진행 상황을 직관적으로 확인할 수 있습니다. /api/conversation/suggestions 엔드포인트로 구현되었습니다.

Claude AI 3.5 Context Analysis Real-time Feedback Emotion Tracking Star Rating
📊 종합 협상 분석 & 성장 추적 시스템

협상 종료 후 AI가 100점 만점으로 성과를 평가하고, 강점/약점/개선 제안을 제공합니다. 사용된 협상 전략, 커뮤니케이션 스타일, 목표 달성도 등을 종합적으로 분석하여 맞춤형 피드백을 생성합니다.

모든 대화는 LocalStorage에 자동 저장되어 언제든지 과거 협상 내역을 조회할 수 있습니다. 히스토리 페이지에서 각 협상의 점수, 피드백을 확인하고 다시 연습할 수 있습니다. 진행률 프로그레스 바로 각 단계별 진행 상황을 실시간으로 확인 가능합니다.

AI Analysis LocalStorage API Progress Tracking History Management Achievement System
🎯 다양한 협상 시나리오 & 난이도 시스템

5가지 실전 시나리오(연봉협상, 계약협상, 프로젝트 관리, 부동산 협상, 팀 리소스 배분)를 제공합니다. 각 시나리오는 초급/중급/고급 난이도로 구분되어 단계적 학습이 가능합니다.

시나리오마다 고유한 NPC 프로필(역할, 성격, 목표, 제약사항)을 설정하여 다양한 협상 스타일을 경험할 수 있습니다. scenarios.js에서 데이터 모델링하고, RESTful API로 시나리오 정보를 제공합니다.

👨‍💻 개발 과정 & 구현 내용

  • 게임 엔진 통합: Phaser 3를 React와 통합하여 게임형 UI 구현, GameScene.js로 씬 관리 및 캐릭터 애니메이션 구현
  • AI 시스템 설계: Claude AI API를 활용한 실시간 대화, AI 응답 선택지 시스템(최대 3회), 메시지별 피드백 시스템 구현
  • 감정 추적 시스템: NPC의 호감도와 감정 상태를 실시간으로 추적하고, 별점 평가(1-5점)로 협상 진행도 시각화
  • 사운드 시스템: soundManager.js를 통한 인터랙티브 오디오 피드백 (메시지 전송, 성공, 실패 등)
  • RESTful API 설계: 8개의 API 엔드포인트 (시나리오 조회, 대화 시작/전송, AI 선택지, 협상 분석 등)
  • 데이터 관리: LocalStorage 기반 대화 기록 저장 및 히스토리 페이지 구현, 세션 관리 시스템 구축
  • 시나리오 시스템: 5가지 협상 시나리오 설계, 난이도별 구분(초급/중급/고급), NPC 프로필 및 목표 데이터 모델링
  • UI/UX 디자인: 게임형 채팅 인터페이스, 실시간 피드백 패널, 진행률 프로그레스 바, 업적 토스트 알림 등

💭 회고 & 향후 계획

✅ 배운 점

이 프로젝트를 통해 게임 엔진을 웹 애플리케이션과 통합하는 전체 과정을 경험했습니다. Phaser 3와 React의 라이프사이클을 조화롭게 관리하는 방법, 게임 오브젝트와 React 컴포넌트 간의 데이터 통신 설계 등 게임형 웹 개발의 핵심 기술을 체득했습니다.

Claude AI의 고급 프롬프트 엔지니어링 경험도 큰 성과였습니다. AI 응답 선택지 생성, 실시간 감정 분석, 메시지 피드백, 종합 협상 분석 등 다양한 AI 기능을 설계하며, System Prompt 구조화, 맥락 관리, JSON 응답 파싱 등의 실무 역량을 크게 향상시켰습니다.

LocalStorage를 활용한 클라이언트 측 데이터 관리, 사운드 시스템 설계, 실시간 UI 업데이트 등 사용자 경험을 극대화하는 다양한 기술적 도전을 해결하며 풀스택 개발 역량을 종합적으로 성장시킬 수 있었습니다.
